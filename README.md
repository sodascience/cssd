# Core social science dataset

Code to create the core social science dataset (CSSD) which captures different social domains in a single table per person-year.

## Installation

Install R and the following packages: 

```R
install.packages(c("tidyverse", "haven", "nanoparquet"))
``` 

## Domains available:
- Demographics
- Household & Family
- Education
- Occupation & Employment
- Income & Wealth
- Social capital & participation
- Health
- Criminality
